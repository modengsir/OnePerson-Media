# 手机零代码使用指南

> 手机用户可用本仓库的**公开提示词流程**，不是把 GitHub SKILL.md 直接安装进 Renoise App。当前 V0.1 没有移动端插件安装器。

## 准备工作

1. 选定平台和视频主题，建议 9:16、30–60 秒。
2. 准备本人或已获明确授权的清晰头像、干净录音；不要上传无权使用的人像和声音。
3. 如果用 Renoise：自行安装官方 App 并登录，确认个人所在地区是否可以下载；官方能力与账户、版本有关。
4. 手机可以使用自己习惯的语音输入法（例如微信输入法）把话说给 Agent，**这不等于 Renoise App 内置了语音对话**。

## 具体操作

1. 打开 `templates/renoise-mobile-prompt.md`，把方括号填好，复制进 Agent。
2. 先让 Agent 产出选题、脚本、分镜，逐项确认。
3. 在 Renoise（或自己的工具）创建数字人，核对脸、发型、声音、口型。
4. 让 Agent 查询当前可用功能与付费项目，**确认预计积分后才允许生成**；先做小样。
5. 继续请求字幕、剪辑、定点修改；如果当前套餐不具备相应能力，就换其他工具完成。
6. 人工按 `references/video-qa.md` 审核，再导出和发布。

## 常见问题

- **不用 Renoise 可以吗？** 可以。选题、脚本、分镜、质检清单和发布文案仍可在支持文字的 AI 助手里使用。数字人和剪辑必须由自选工具完成。
- **Agent 对话是免费的吗？** Renoise 官方说明聊天本身不消耗生成积分，但账号订阅/其他付费任务是另一回事；实时条款以官网为准。
- **怎么修正“Renoise”读错？** 在生成前把英文词列入读音清单，成片在对应时间点复听。提示 Agent 修改“00:12 这处名称读音”，避免整片重做。
- **手机网页版同步一定支持所有素材吗？** 以你当前账号、项目与工具界面为准，不保证所有功能和文件格式完全一致。
