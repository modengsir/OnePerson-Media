# Agent 用户指南：Codex / Claude Code / 其他支持 Skill 的助手

## 1. 让助手读取主 Skill

打开本仓库的 `SKILL.md`，并将 `references/`、`templates/` 一起放在所用 Agent 可读取的 Skill 目录；不同工具支持的目录和安装方式不完全相同，请优先参考其官方帮助。

启动指令示例：

> 请使用 OnePerson Media Skill，为我做一条 45 秒的 AI 数字人口播，主题是“如何把工具实测做成自媒体视频”。先做 3 个开头方案和脚本，不要生成或扣费；我会确认每一步。

## 2. 可选：连接 Renoise 官方 MCP

仅当用户主动选择 Renoise 时，打开 <https://renoise.ai/mcp>，按照该页面中 Codex / Claude Code 的**最新官方安装方式**完成 Renoise 插件或 MCP 连接。连接成功后，可先尝试“查询 Renoise 余额和可用模型”，再逐项测试生成能力。MCP 连接与实际付费生成是两回事。

> 本仓库 V0.1 尚未提供或验证“通过此仓库脚本自动调用 Renoise API 完成视频”的端到端适配器。真正的视频生成由支持该服务的 Agent / 官方插件或人工网页操作负责，不要把提示词模板等同于代码自动集成。

## 3. 自动化边界

Agent 应在每次付费操作前：查看当前套餐能力 → 查询实际预计积分 → 说明单项与累计费用 → 要求明确确认 → 再执行。费用未知或用户未同意时停止。所有生成完成后由创作者审核。

注意官方说明：某些客户端的 MCP 只支持素材生成，不支持完整云端剪辑（例如 ChatGPT 的 Renoise MCP 页面说明），所以不能承诺“在所有 Agent 中自动完成剪辑”。
