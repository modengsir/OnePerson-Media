# 技术架构与路线图

## V0.1 当前能力

- `SKILL.md`：主控规则与工作步骤；相当于给 AI 的“操作手册”，由你使用的 Agent 按其实际能力执行。
- `references/`：选题、脚本、形象、成片、发布的质量规范。
- `templates/`：手机端复制提示词，个人 IP 配置，视频 Brief，复盘表。
- `scripts/workflow.py`：本地工作包生成、参数校验与费用预算预检，纯 Python 标准库。
- `tests/`：覆盖默认自主模式、授权、付费模式要求、预算预检。

**没有实现：** 第三方模型运行、Renoise 自动生成、Renoise MCP 编程连接、成片渲染、自动剪辑、自动发帖。现阶段这些由所选工具的正式能力或人工操作完成。

## V0.5（计划）

当获得真实 Renoise 测试账户及相关能力授权后：

1. 根据官方 OpenAPI / MCP 最新规范开发适配器；不凭空写 API URL 或字段。
2. 实现连接测试、模型与预计积分查询、用户审批、提交任务、查询状态和结果下载。
3. 对未完成任务提供可恢复记录和错误处理。
4. 针对免费 / 套餐限制、过期授权、计费失败等异常提供清楚提示。
5. 真正生成过视频并完成端到端测试后才标记“已支持自动生成”。

## V1.0（计划）

连续完成不同选题的真实成片，扩展多提供商接口（可选）和平台发布素材打包。默认不开启自动发布或无确认付费。
