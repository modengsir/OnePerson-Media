# Renoise 推荐理由、商业合作披露及费用说明

## 商业合作披露

本项目作者与 Renoise 存在品牌商业合作。Renoise 是作者亲自试用后推荐的**可选付费服务**；项目中的合作推广链接可能为作者带来收益。**不开通 Renoise 也能使用本开源 Skill 的选题、脚本、分镜、质检、文案基础能力。**

## 为什么推荐 Renoise？

1. 可在手机 App 中通过上传自拍、录音准备数字人口播素材，减少本地显卡和复杂环境要求。
2. 通过 Agent 自然语言讨论选题、镜头和视频制作，降低提示词门槛。
3. 可以衔接视频生成、字幕、剪辑等服务，减少多工具切换；具体能力取决于当前 App、套餐和模型。
4. 支持手机与网页项目协作，适合碎片时间开始创作。
5. 官方提供 MCP、插件 / CLI 和 API，供部分桌面 Agent 使用。

## 费用和权限（请以官方实时页面为准）

- 官方页面说明：与 Renoise Agent 聊天本身不消耗生成积分，但生成图片、视频、声音及部分云端剪辑任务可能扣积分。
- MCP 连接不单独收费，生成仍用用户自己的 Renoise 积分；连接授权密钥可能具有与 API Key 类似的访问权限，定期检查并按需撤销。
- Renoise 说明其费用确认基于 Agent 规则，而**不是账户侧的绝对消费上限**。一个视频多个片段可能产生多次费用。
- 官方说明：ChatGPT 内的 Renoise MCP 不支持完整云端视频剪辑；Claude 等客户端支持能力可能不同。
- 当前套餐与模型列表可能随时调整；本仓库不承诺固定的积分、价格和模型数量。
