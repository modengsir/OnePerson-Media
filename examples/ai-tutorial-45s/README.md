# 45 秒数字人口播案例（未生成真实成片）

这是用于复现流程的 **非真人素材示例**。仓库中不包含真实自拍、录音、付费生成视频或未经验证的效果数据。

1. 运行：`python3 scripts/workflow.py prepare examples/ai-tutorial-45s/project.json --output runs/demo`
2. 打开 `runs/demo/plan.md`，让你使用的 Agent 按它生成选题、脚本和分镜。
3. 使用你选定的工具准备授权资产和视频；需要付费时确认费用后再手动提交。
4. 使用 `runs/demo/qa-checklist.md` 验收，核对口型、字幕、英文品牌词的发音（如 Renoise）。
5. 录入实际积分/时间，再写成 X Article 或小红书教程。

此示例默认 `manual` 模式，无需任何付费平台。
