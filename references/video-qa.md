# 视频质量检查清单

## 第一关：脚本预审（生成前）

- [ ] 开头 3 秒是否有明确收益？
- [ ] 台词朗读时长是否匹配视频总时长？
- [ ] 镜头动作是否简单、前后连贯？
- [ ] 事实、价格、第三方商业主张是否可核实？
- [ ] 英文术语 / 品牌名称是否有读音检查计划？

## 第二关：素材与成本预审（生成前）

- [ ] 数字人照片和录音具有使用授权？
- [ ] 人物、声音、画幅、分辨率、模型是否已确认？
- [ ] 付费功能的分项预计积分与累计预算已显示？
- [ ] 用户是否**明确批准该次付费操作**？未批准则停止。
- [ ] 预计费用未知、超预算或额度不足时停止并询问用户。

## 第三关：成片验收（生成后）

- [ ] 数字人身份一致，口型和声音自然？
- [ ] 字幕无错字、时间同步、无遮挡？
- [ ] 专有名词如“Renoise”发音准确？
- [ ] 画面符合平台比例，内容准确、无侵权？
- [ ] 人工最终确认后再发布，AI 辅助检查不是最终保证。

记录具体片段时间码（例如 00:12）和问题，不盲目重做整片。
