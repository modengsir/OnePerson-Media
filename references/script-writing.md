# 口播脚本与分镜规则

- 先定视频时长和平台画幅：默认 9:16、45 秒，可由用户修改。
- 分镜尽量每镜头只描述一项关键动作，复杂任务拆成更短片段。
- 口语化、避免宣传稿语气：实测结果、具体步骤和限定条件优先。
- 开头 3 秒立即呈现问题或效果，结尾只设计一个自然 CTA。
- 口播稿要估算朗读时长，宁少勿挤；允许停顿、反应镜头和画面演示。
- 英文名称列读音校验项，例如 `Renoise`、`MCP`、`Skill`，必要时要求试听并修正。
- 输出表格字段：起止秒数、口播文本、人物动作、B-roll、字幕重点、质检要点。
- 在生成前要求用户确认脚本与分镜。未经授权不能替换真人脸或声音。
